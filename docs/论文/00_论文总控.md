# 论文总控

## 1. 论文定位

推荐中文题目：

> 面向 PyTorch 编译训练的端到端峰值显存感知激活重计算方法

推荐英文题目：

> PeakAware: End-to-End Peak-Constrained Activation Placement for Compiled PyTorch Training

论文研究的是静态 shape、单设备训练下的 activation SAVE/RECOMPUTE 选择。Optimizer 位于
joint graph 外，但必须进入完整 step 的 fixed memory、phase peak 和 runtime measurement。

不纳入核心范围：FSDP/ZeRO、offload、activation compression、任意 backward schedule 搜索、
dynamic shape、MoE routing 和多机联合优化。

## 5. 研究问题

| 编号 | 问题 | 主要回答方式 |
|---|---|---|
| RQ-1 | saved-memory 目标与完整训练物理峰值存在多大错位，原因是什么 | phase peak、gap、D0--D5 |
| RQ-2 | storage/fixed/compiler-aware 模型能否预测峰值大小与 phase | raw/calibrated error、phase accuracy |
| RQ-3 | PeakAware 是否比真实 min-cut、block AC、SAC 更可靠地满足物理预算 | violation、OOM、fallback |
| RQ-4 | 相同实测峰值下 PeakAware 是否提高有效吞吐 | Pareto、samples/s 或 tokens/s |
| RQ-5 | 搜索、profiling、Top-K 和 cache 成本是否可摊销 | ranking、compile cost、hit rate、steps |

Hints 消融归入 RQ-3/RQ-5，不单独扩展主线。

## 6. 论文级完成定义

- 所有核心 claim 均有至少一个冻结 `EV-*`，且没有反证未解释；
- 所有 baseline 使用真实实现或在名称中明确标记 `proxy`；
- 所有模型名称与实际层数、宽度、输入长度一致；
- 所有结果来自同一冻结代码、环境和测量协议；
- raw 与 calibrated 结果并列，负结果进入正文或局限性；
- 图表可由 raw records 一条命令重建；
- 摘要、引言、结论中的数字可回溯到同一个 evidence ledger；
- 答辩中的每个贡献页都有代码入口、实验和边界。
