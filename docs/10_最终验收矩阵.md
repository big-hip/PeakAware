本文档用于把 `docs/07_实验与论文产出计划.md` 和 `docs/08_min-cut缺口诊断与根因分析.md`
中的最终要求落到可审计证据。它不是完成声明；所有状态都必须由当前代码、测试、实验产物或
命令输出证明。

## 2. 效果导向验收项

| 目标 | 当前结构化指标 | 输出位置 | 完成判据 |
|---|---|---|---|
| 实测峰值降低 | `selected_measured_peak_reduction_vs_all_save_bytes`、`mean_measured_peak_reduction_vs_all_save_bytes` | experiment records/summary | 主模型矩阵中多数预算点为正，且 budget violation rate 低于关键基线 |
| 相同峰值下吞吐 | `selected_samples_per_second_speedup_vs_all_save`、variant summary | experiment records/summary | 按实测 peak 分桶后，PeakAware 吞吐不低于或优于关键基线 |
| 模拟准确度 | `mean_absolute_relative_error`、`within_10_percent_rate`、`phase_classification_accuracy`、D0-D5 layered accuracy | `topk_correction.simulation_accuracy`、experiment summary、layered accuracy JSON | GPU 稳态 repeats 下 MRE/P90/max 达到论文设定阈值，并报告 D0-D5 误差变化 |
| 峰值根因分析 | `diagnostic.evidence`、`plan_diagnostics`、D0-D5 counterfactuals、root cause counts、synthetic root-cause precision/recall | result report、experiment summary、root-cause benchmark JSON | 合成 ground-truth 图上 root-cause precision/recall 达标；真实模型报告根因频率 |
| hints 消融 | `diagnostic_hints_enabled`、`diagnostic_hint_count`、`repair_success_rate`、variant summaries | experiment records/summary/variant summary | hints on 相比 off 改善搜索效率、预算满足率或正确提前终止 |

## 3. 推荐验收命令

小规模 CI 验证：

```bash
conda run -n torch2.13-gpu python -m pytest tests/unit tests/integration tests/correctness -q
```

诊断 hints 消融 smoke：

```bash
conda run -n torch2.13-gpu python scripts/run_experiments.py \
  --tasks tiny_residual_w8,tiny_mlp_w8_d3,tiny_attention_w8_s4 \
  --budget-mib 128,256 \
  --microbatches 1,2 \
  --top-k 3 \
  --diagnostic-hints both \
  --measurement-repeats 3 \
  --output-json artifacts/smoke_records.json \
  --output-csv artifacts/smoke_records.csv \
  --output-summary-json artifacts/smoke_summary.json \
  --output-variant-summary-json artifacts/smoke_variant_summary.json \
  --output-hint-ablation-json artifacts/smoke_hint_ablation.json \
  --output-baseline-comparison-json artifacts/smoke_baseline_comparison.json \
  --output-layered-accuracy-json artifacts/smoke_layered_accuracy.json
```

合成根因 ground-truth 验证：

```bash
conda run -n torch2.13-gpu python scripts/run_root_cause_benchmark.py \
  --output-json artifacts/root_cause_accuracy.json
```

外部 PyTorch baseline 可用性/provenance：

```bash
conda run -n torch2.13-gpu python scripts/inspect_external_baselines.py \
  --output-json artifacts/external_baselines.json
```

PyTorch SAC baseline 实测：

```bash
conda run -n torch2.13-gpu python scripts/run_sac_baseline_matrix.py \
  --tasks vit_b_16,bert_base,gpt2 \
  --microbatches 1 \
  --device cuda \
  --measurement-warmup-steps 5 \
  --measurement-repeats 20 \
  --output-json artifacts/sac_main_matrix.json
```

从已保存 records 离线生成合并 SAC 的 baseline report：

```bash
conda run -n torch2.13-gpu python scripts/summarize_baseline_comparison.py \
  artifacts/main_records.json \
  --sac-baseline-json artifacts/sac_main_matrix.json \
  --output-json artifacts/main_baseline_comparison.json
```

计划 artifact 离线身份校验：

```bash
conda run -n torch2.13-gpu python scripts/validate_plan_artifacts.py \
  artifacts/main_plan_artifacts/*.json \
  --output-json artifacts/main_plan_validation.json
```

主模型验收实验应在固定 GPU 和足够 repeats 下运行：

```bash
conda run -n torch2.13-gpu python scripts/run_experiments.py \
  --tasks resnet50,vit_b_16,bert_base,gpt2 \
  --budget-mib <按机器显存设置多个预算点> \
  --microbatches <按模型设置多个 batch 点> \
  --top-k 5 \
  --device cuda \
  --diagnostic-hints both \
  --measurement-warmup-steps 5 \
  --measurement-repeats 20 \
  --cache-root artifacts/cache \
  --profile-db artifacts/profiles.sqlite \
  --plan-artifact-dir artifacts/main_plan_artifacts \
  --output-json artifacts/main_records.json \
  --output-csv artifacts/main_records.csv \
  --output-summary-json artifacts/main_summary.json \
  --output-variant-summary-json artifacts/main_variant_summary.json \
  --output-hint-ablation-json artifacts/main_hint_ablation.json \
  --sac-baseline-json artifacts/sac_main_matrix.json \
  --output-baseline-comparison-json artifacts/main_baseline_comparison.json \
  --output-layered-accuracy-json artifacts/main_layered_accuracy.json
```

## 4. 不得宣称完成的条件

只要以下任一项缺失，就不能宣称完整 PeakAware：

- 没有主模型真实测量矩阵；
- 没有与关键 baseline 的预算满足率和吞吐对照；
- Top-K 误差只来自 CPU 或单 step smoke；
- root-cause accuracy 没有 synthetic ground-truth precision/recall；
- hints on/off 只有字段导出，没有实验对比结论；
- 报告没有保存 raw JSON/CSV、环境 fingerprint、配置和 cache/profiling 产物。
