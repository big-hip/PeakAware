## 3. 推荐验收命令

小规模 CI 验证：

```bash
conda run -n torch2.13-gpu python -m pytest tests/unit tests/integration tests/correctness -q
```

诊断 hints 消融 smoke：

```bash
conda run -n torch2.13-gpu python scripts/run_experiments.py \
  --tasks tiny_residual_w8,tiny_mlp_w8_d3,tiny_attention_w8_s4 \
  --budget-mib 128,256 \
  --microbatches 1,2 \
  --top-k 3 \
  --diagnostic-hints both \
  --measurement-repeats 3 \
  --matrix-passes 2 \
  --output-json artifacts/smoke_records.json \
  --output-csv artifacts/smoke_records.csv \
  --output-summary-json artifacts/smoke_summary.json \
  --output-variant-summary-json artifacts/smoke_variant_summary.json \
  --output-hint-ablation-json artifacts/smoke_hint_ablation.json \
  --output-cache-reuse-json artifacts/smoke_cache_reuse.json \
  --output-baseline-comparison-json artifacts/smoke_baseline_comparison.json \
  --output-layered-accuracy-json artifacts/smoke_layered_accuracy.json
```

```bash
conda run -n torch2.13-gpu python scripts/run_root_cause_benchmark.py \
  --output-json artifacts/root_cause_accuracy.json
```

```bash
  --output-json artifacts/external_baselines.json
```

## 4. 当前 GPU 验收证据

`2026-07-19` 在 `torch2.13-gpu`、RTX A6000 上保存了两组主模型 artifact：

| Artifact 前缀 | 覆盖范围 | 关键结果 |
|---|---|---|
| `artifacts/main_v2_*` | `resnet50,vit_b_16,bert_base,gpt2`；预算 4096/8192 MiB；mb1；hints on/off；2 passes；repeats=20 | `32/32 ok`；budget violation `0`；mean peak reduction vs all-save `41,589,824` bytes；mean speedup vs all-save `1.0366`；calibrated mean relative error `0.0671`；warm-pass cache hit rate `1.0`；plan validation `32/32 valid` |
| `artifacts/main_mb2_*` | 同一模型/预算；mb2；hints on/off；repeats=20 | `16/16 ok`；budget violation `0`；mean peak reduction vs all-save `118,710,656` bytes；mean speedup vs all-save `1.0402`；calibrated mean relative error `0.0686`；plan validation `16/16 valid` |

缓存证据按层解释：默认 `capture_backend=auto` 会优先走 AOTAutograd，当前 PyTorch 2.13 的 AOT
GraphModule 不进入持久 capture cache，因此主矩阵 warm pass 的 `cache_hit_rate=1.0` 证明的是
analysis/executable 层复用；集成测试单独证明启用 capture cache 时同 key 命中后不会重新真实捕获。

对应外部 SAC baseline：

- `artifacts/sac_main_matrix.json`：mb1，`3/3` usable，mean peak reduction `0` bytes，speedup vs eager `0.4442`；
- `artifacts/sac_main_mb2_matrix.json`：mb2，`3/3` usable，mean peak reduction `673,109` bytes，speedup vs eager `0.4392`。

## 5. 不得宣称完成的条件

只要以下任一项缺失，就不能宣称完整 PeakAware：

- 没有主模型真实测量矩阵；
- 没有与关键 baseline 的预算满足率和吞吐对照；
- Top-K 误差只来自 CPU 或单 step smoke；
- root-cause accuracy 没有 synthetic ground-truth precision/recall；
- hints on/off 只有字段导出，没有实验对比结论；
- 报告没有保存 raw JSON/CSV、环境 fingerprint、配置和 cache/profiling 产物。
